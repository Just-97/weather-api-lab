# Как выложить проект на GitHub

Публикуйте **содержимое** распакованной папки `weather-api-lab`. В корне репозитория должны лежать `README.md`, `index.html`, `styles.css`, `app.js` и папка `docs`. Тогда GitHub покажет README при открытии репозитория, а учащиеся смогут скачать весь проект. Аккаунт GitHub нужен тому, кто публикует; для скачивания из публичного репозитория учащимся он не нужен.

1. Войдите на GitHub и создайте репозиторий через **New repository**. Название выберите сами, например `weather-api-lab`. Если ученики должны скачивать проект без приглашения, выберите **Public**. Оставьте опцию добавления README выключенной: готовый README уже есть в проекте.
2. На странице пустого репозитория нажмите **uploading an existing file** (если в нём уже есть файлы: **Add file → Upload files**).
3. Перетащите четыре файла и папку `docs` из распакованной папки в область загрузки. Проверьте, что `README.md` находится в корне, а файлы материалов — внутри `docs`.
4. Кратко опишите изменения, например `Добавить учебный погодный сервис`, и нажмите **Commit changes**. Откройте главную страницу репозитория и убедитесь, что README отображается, а ссылки на сценарий и снимок открываются.
5. Скопируйте из адресной строки **фактическую ссылку на репозиторий** и передайте её группе. Для самопроверки скачайте **Code → Download ZIP**, распакуйте в другую папку и запустите `index.html`.

[Справка GitHub по загрузке файлов через сайт](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository).
