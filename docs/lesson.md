# Живой показ: 13 минут

После показа учащийся сможет найти HTTP-запрос в браузере и объяснить, как одно поле JSON стало текстом на странице. Подготовьте заранее три вкладки: готовый сайт, [прямой запрос для Минска](https://api.open-meteo.com/v1/forecast?latitude=53.9&longitude=27.57&current=temperature_2m) и редактор с [app.js](../app.js). Увеличьте масштаб на проекторе. Откройте Network на вкладке сайта, включите Fetch/XHR и Disable cache.

| Время | Что показать | Что спросить или сказать |
| --- | --- | --- |
| 0–2 мин | Выберите Минск, нажмите «Показать погоду». | «Страница уже знает координаты Минска. Откуда она узнаёт температуру?» После ответа покажите схему из README: браузер отправил GET, сервер вернул JSON. |
| 2–4 мин | Откройте прямой запрос. Выделите параметры `latitude`, `longitude`, `current` и найдите `temperature_2m` в ответе. | «Если заменить координаты, что изменится в ответе? Как проверить догадку?» |
| 4–7 мин | Вернитесь в Network. Откройте `forecast`, укажите GET и статус 200 в Headers. В Response найдите `current.temperature_2m`. | Попросите кого-нибудь назвать число из ответа и найти его на странице. Уточните, что JSON пришёл текстом, а JavaScript разобрал его. |
| 7–10 мин | В редакторе покажите `buildWeatherUrl`, затем две строки с `await`, затем присваивание `temperature.textContent`. | «Первый `await` ждёт объект ответа; второй читает его тело. В какой строке число стало видно на странице?» |
| 10–12 мин | Включите Offline в Network и повторите запрос. Верните No throttling, нажмите снова. | Покажите `catch` и `finally`. Спросите: «Чем отсутствие связи отличается от HTTP 400?» Подведите к мысли: в первом случае ответа нет, во втором сервер ответил и указал причину статусом. |
| 12–13 мин | Покажите, где скачать ZIP и где начать лабораторную. | Попросите учащихся назвать или записать три звена: URL запроса → поле JSON → элемент HTML. |

Если хотите показать HTTP 400 за те же 13 минут, на отметке 10:00 вместо Offline на отдельной вкладке откройте [запрос с широтой 999](https://api.open-meteo.com/v1/forecast?latitude=999&longitude=27.57&current=temperature_2m). Откройте Network до перехода или обновите вкладку с открытым Network. Покажите статус и тело ошибки, затем найдите в коде `!response.ok`. Рабочий файл при этом менять не нужно.

Если интернет в аудитории недоступен, покажите [снимок сводки](screenshot.jpg) и [сохранённый JSON](example-response.json) рядом. Попросите найти в JSON источник каждого числа на снимке. Дальше покажите сетевую ошибку на локальной странице. Шаги лабораторной с живым запросом выполните, когда появится связь.

После показа: [лабораторная](../README.md#лабораторная-от-url-до-страницы) и [тест-кейсы](../README.md#проверка-работы). Если время осталось только на одно упражнение, дайте шаги 1–3: открыть URL, увидеть число в Console, вывести его на страницу.
